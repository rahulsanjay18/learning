Free response (graded later)

Explain spaced repetition to a friend in two or three sentences.

Mentions: reviewing just before forgetting; growing intervals; retrieval, not rereading.
Review something just as you're about to forget it, then wait longer before the next review. Each successful recall makes the memory last longer.

Expand \(2x(x+1)\).

\(2x \cdot x + 2x \cdot 1 = 2x^2 + 2x\).

\(X\) is 1 with probability \(p\) and 0 otherwise. What is \(\operatorname{Var}(X)\) in terms of \(p\)?

\(E[X^2] - (E[X])^2 = p - p^2 = p(1-p)\). Any equivalent form is accepted.

Python plugin

Runnable Python (Pyodide, loaded on the first Run). The central limit theorem: means of 30 uniform draws pile up in a bell around 0.5, with spread σ/√n.

import numpy as np

rng = np.random.default_rng(1)
n, reps = 30, 10_000
means = rng.uniform(0, 1, size=(reps, n)).mean(axis=1)

sigma = (1 / 12) ** 0.5            # SD of one Uniform(0, 1) draw
print(f"mean of means: {means.mean():.4f}  theory 0.5")
print(f"SD of means:   {means.std():.4f}  theory {sigma / n ** 0.5:.4f}")   # σ/√n

counts, edges = np.histogram(means, bins=9)
for c, lo in zip(counts, edges):
    print(f"{lo:.3f} {'#' * (c // 125)}")

One answer: return sum((x - m) ** 2 for x in xs) / (n - 1). For [1, 2, 3, 4] that is 5/3 ≈ 1.667; dividing by n would give 1.25. Deviations from \(\bar{x}\) run a little smaller than deviations from the true mean, and n − 1 corrects for it (Bessel's correction).
