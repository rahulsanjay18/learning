# New books on the server: are they useful? (2026-10-06)

**Method.** I compared the book server against `library/MANIFEST.csv`. The server has no "list everything" call, so I searched
titles by substring. One sweep found 286 books, 24 of them not in the manifest. A second, wider sweep sent about 3,000
requests and overloaded the server, which then returned 502 errors for both `/books` and `/progress`. **So this list is partial.**
To make this a single request next time, I added `GET /catalog` to `book-server/app.py` and `python3 scripts/books.py new`.
Both need a redeploy.

All 24 new books are grade A, so their text can be taught from, quoted, and used for equations (`library/README.md`).
