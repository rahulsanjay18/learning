# Indian History syllabus

Planned ahead (2026-10-06) so each session only has to *write* the next lesson, not design it. Each lesson has a reading and 2–3
objectives. Objectives are graded **Got it / Not yet** (mastery rule: `TEACHING-LOG.md` rule 20). A "Not yet" adds a short re-teach
section to the next lesson; the syllabus changes only when a gap needs more than that, and every change goes in "Changes" at the bottom.

Spine: Kulke & Rothermund, *A History of India* (K&R; library id 621b57ff65). The EPUB has no page numbers, so readings go by
section heading; page counts are estimates (~50 lines a page on the book server). Pace: Indian History gets 2 blocks a week, and a
lesson is usually 2 blocks (read, then lesson), so **about one lesson a week**.
