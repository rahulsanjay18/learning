Clean lines

Draw one-pixel lines with no doubles and no jaggies, then make your first ones in LibreSprite. About 15 minutes.

Every sprite and illustration you want to make starts as lines: an outline is what makes a character readable at 32×32. At that size each pixel carries a lot of weight, so the course you'll read next says line accuracy is critical.2 You don't need to be able to draw for this. Clean lines follow three mechanical rules.

1 · Three rules

Rule 1: connect diagonally, never in an L

A one-pixel line should touch each next pixel only at a corner. Two pixels that form a right-angle corner add an extra pixel the line doesn't need, called a double. Doubles make lines look thick and messy.17

Rule 2: in a straight line, every segment is the same length

A diagonal pixel line is a staircase. Each flat or upright run of pixels is a segment. If every segment is the same length, the eye reads a straight line. If the lengths jump around (3, 1, 2, 3…), you get jaggies: bumps that break the line.17

The cleanest slopes use segments of 1 or 2. Les Forges calls these the perfect lines: 1:0 (flat), 2:1, 1:1, 1:2 and 0:1 (upright).2

Notation: in this course, 2:1 means 2 across per 1 down (flat segments of length 2). Some tutorials write the ratio the other way round. The set of perfect lines is the same either way.

Rule 3: in a curve, segments change gradually

A curve is a line whose slope changes, so its segments must change length too, but progressively:2 longest where the curve is flattest (or most upright), shortest at the diagonal.1

The math version. Write each segment's slope as pixels across per pixel down (a flat run of 3 is 3, an upright run of 3 is ⅓, a single pixel is 1). Then a straight line is a constant sequence, and a clean convex curve is a monotonic one, like 3, 2, 1, 1, ½, ⅓. A jaggy is any place the sequence breaks that pattern. The checker in section 3 tests exactly this.

2 · Spot it

Name the problem. Answer from the rules, not the pictures above.

1. A straight line?

Jaggy. Segments go 3, 1, 2, 3, 1, 2, 2. A straight line needs one repeated length.

2. A quarter of a circle?

Clean. 3, 2, 1, 1, then upright 2, 3: the slope falls steadily from flat to upright, and every join is diagonal.

3. A straight line?

Double. Near the top, three pixels form an L. Delete the rightmost pixel of the run of three and you're back to a clean 2:1 line.

4. A quarter of a circle?

Jaggy. 3, 1, 3: the curve gets steep, then flat again, then steep. That reads as a bump, not a curve.

5. A straight line?

Clean. Every segment is one pixel: a perfect 1:1 line.

6. A quarter of a circle?

Double. The segment lengths are fine, but one extra pixel makes an L where the 3-segment meets the 2-segment.

3 · Draw it here

Click or drag to paint, click a painted pixel to erase. Check gives instant feedback, with problems marked in red. Try without the example first.

Drill B: a quarter circle from A to B

4 · Do it in LibreSprite

LibreSprite is a free, GPL-2.0 sprite editor. It was forked from Aseprite in 2016, at the last commit Aseprite released under the GPL, so most Aseprite tutorials carry over.5

Install (pick one)

  • Linux: flatpak install flathub com.github.libresprite.LibreSprite6
  • Windows: download the latest build from the GitHub releases page.5
  • Nothing to install: the browser version on the official site works for today.

Ten minutes of lines

  1. Ctrl+N → new sprite, 32 × 32, RGB, transparent background.3 Start small. Expand the canvas later if you need to.4
  2. Zoom in (Z is the zoom tool, or use the scroll wheel). Pick the pencil (B) at size 1.3
  3. Draw a 2:1, a 1:1 and a 1:2 line, counting pixels as you go.
  4. Experiment. The brush options bar has a Pixel Perfect checkbox.3 Draw one quick freehand curve with it off, and one with it on. Which rule does it enforce for you, and which one is still your job?
  5. Draw the quarter circle from Drill B by hand. Then mirror it to make a full circle. Fix doubles with the eraser (E).
  6. Ctrl+S saves a .ase file you can keep editing. For sharing, use File → Save Copy As with its resize option at 800% to get a PNG.3 Only scale by whole numbers (200%, 300%, 800%…): that keeps every pixel square and sharp.4
