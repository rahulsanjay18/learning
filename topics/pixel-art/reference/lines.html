Lines

The rules for one-pixel lines, plus LibreSprite basics. Print it, or keep it beside the canvas.

Terms

Segment: one straight run of pixels in a line (flat, upright, or a single pixel). Neighbouring segments meet at a corner, diagonally.
Double: an unneeded pixel that makes a right-angle (L-shaped) corner in a 1px line.1
Jaggy: a bump caused by uneven segment lengths, in a line that should look straight or smoothly curved.4
Perfect line: a straight line with slope 1:0, 2:1, 1:1, 1:2 or 0:1.2 In this course a:b means a across per b down.

The three rules

  1. Diagonal joins only. No L corners. Break this on purpose only to make a sharp corner.1
  2. Straight = equal segments. Prefer perfect lines.12
  3. Curve = segments change progressively. Longest where the curve is flat or upright, shortest at the diagonal.12

Test: write each segment's slope (flat run of n = n, upright run of n = 1/n, single = 1). Straight: constant sequence. Curve: monotonic sequence.
