## Course description
An optional practicum: three real analyses from raw data to a written report. One is an A/B test from raw event logs, one a
regression on public data, and one a Bayesian model. Each report is short, around three pages, and written for a reader who
didn't do the analysis. Much of the work is the messy part textbooks skip: cleaning, choosing the question, and saying what the
data can't tell you.

## Learning objectives
By the end of this course you can:
1. Turn a vague question into one the data can answer, and say which question you're not answering.
2. Clean and document a real data set so someone else can reproduce your analysis.
3. Choose, fit and check a model suited to the question.
4. Write a report with a clear conclusion, uncertainty stated honestly, and the limits named.

## Texts
- **Required:** none new. Use what you learned in S310, S320 and S340.
- **Recommended:** Bruce, Bruce and Gedeck, *Practical Statistics for Data Scientists* (in your library), as a quick reference.
