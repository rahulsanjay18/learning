Effect size and confidence intervals

Two blocks: the reading (about 20 minutes), then this page (about 25). One win: say how big an effect is, and how sure you are, in one sentence.

Notes: answer the four boxes below in your own words while you read (a sentence or two each). They reach me with your results, and I'll reply to them next session.

Casella & Berger say that moving from a single number to an interval means giving up some precision. What do we gain in exchange (their Example 9.1.3)?

Confidence: a positive, quantifiable probability that the interval covers the parameter (≈ .9544 in their example), where a point estimate is exactly right with probability 0.

In your own words: what is the coverage probability of an interval estimator (Definition 9.1.4)?

The probability that the random interval [L(X), U(X)] contains the true parameter, computed over repeated samples.

In a confidence interval, which is random: the interval or the parameter? Why does that matter for how you phrase a result?

The interval is random ("the interval is the random quantity, not the parameter", p. 418); the parameter is fixed. So "95%" describes the procedure across samples, not the probability that the parameter lies in one computed interval.

Block 2: the lesson

Warm-up (from memory)

Test A has \(p = 0.002\), test B has \(p = 0.04\). Does A have the bigger effect?

\(p\) comes from \(z = \text{effect}/\text{SE}\), and SE shrinks with \(n\). A could be a tiny effect measured on millions of users.

A Type II error is…

Not rejecting \(H_0\) when there really is an effect. Its rate is \(\beta\); power is \(1-\beta\).

1 · Effect size: "how much?"

The p-value answers "is it surprising if nothing's going on?". Effect size answers "how big is the difference?", in units someone cares about. Two common versions, using lesson 2's A/B test (5.0% → 5.6% conversion):

  • Absolute difference: \(5.6\% - 5.0\% = 0.6\) percentage points. "Percentage points" is the unit for a difference between two percentages.
  • Relative lift: \(0.6 / 5.0 = 12\%\). The same change, stated relative to the starting point. It sounds bigger, which is why it's popular in slide decks; always say which one you mean.

Sign-ups go from 4.0% to 4.5%. What is the relative lift, in percent? (You can type an expression.)

Absolute: 0.5 points. Relative: \(0.5/4.0 = 12.5\%\).

2 · Statistically significant vs. worth it

Before a test, decide the smallest effect worth acting on: the lift that would pay for building and maintaining the change. Bruce, Bruce & Gedeck call this the effect size you "hope to be able to detect", and it's what power is computed for.2 Say it's 0.5 points for the checkout page. Then "significant" (detectably not zero) and "worth it" (at least 0.5) are separate questions.

Smallest lift worth acting on: 0.5 points, \(\alpha = 0.05\). Sort each result.

The 0.05-point lift is real but irrelevant. The 0.9-point lift might be worth it, but 400 users can't tell it apart from noise: not significant isn't the same as "no effect".

3 · The confidence interval: size and uncertainty together

A 95% confidence interval is the estimate plus or minus about two standard errors:

$$\text{estimate} \pm 1.96 \times \text{SE}$$

For the A/B test: estimate 0.6 points, SE 0.29 points, so

$$0.6 \pm 1.96 \times 0.29 \;\Rightarrow\; [\,0.03,\ 1.17\,] \text{ points}$$

One line tells you three things:

  • Size: the middle, 0.6 points.
  • Uncertainty: the width. Anything from a negligible 0.03 to a big 1.17 points is plausible.
  • Significance: 0 is just outside, which matches \(p = 0.038 < 0.05\). A 95% interval excludes 0 exactly when a two-sided test at \(\alpha = 0.05\) rejects (normal-approximation version).

4 · What the "95%" means

This is the pretest question you missed. The true lift is a fixed number we don't know. The interval is what changes from sample to sample: "the interval is the random quantity, not the parameter" (Casella & Berger, p. 418).1 So "95%" describes the procedure: build intervals this way over and over, and about 95% of them will contain the true value. Run this simulation a few times (each run builds 100 intervals for a mean whose true value is 10):

import random, math

true_mean, sd, n = 10, 2, 25
covered = 0
for i in range(100):
    xs = [random.gauss(true_mean, sd) for _ in range(n)]
    xbar = sum(xs) / n
    half = 1.96 * sd / math.sqrt(n)
    if xbar - half <= true_mean <= xbar + half:
        covered += 1
print(covered, "of 100 intervals contain the true mean")

Expect numbers in the low-to-high 90s, averaging 95. Any single interval either contains 10 or doesn't; the 95% is the hit rate of the method.

Practice

An estimate is 2.0 with standard error 0.5. What is the lower end of its 95% confidence interval?

\(2.0 - 1.96 \times 0.5 = 1.02\). (Upper end: 2.98.)

The interval is [0.03, 1.17] points. Which reading is correct?

The 95% belongs to the method. The first option treats the true lift as random, which is the Bayesian "credible interval" reading, not a confidence interval.

From memory: one sentence for your PM that gives the effect size and its uncertainty for this A/B test.

"We estimate the new page lifts conversion by about 0.6 percentage points (12% relative), and the data are consistent with anything from almost nothing (0.03) to about 1.2 points, so it's probably helping, but we can't yet say it clears our 0.5-point bar." Avoid: "there's a 95% chance the lift is between 0.03 and 1.17."
