Power: how often a real effect gets caught

Two blocks: the reading (about 20 minutes), then this page (about 25). One win: compute a test's power for a specific effect, and the sample size that would give 80%.

Block 1: read first

Reading

  1. Casella & Berger, Statistical Inference, §8.3.1 "Error Probabilities and the Power Function", pp. 382–385: from the start of §8.3 to the end of Example 8.3.4. Stop before Definition 8.3.5.
  2. Companion, if you want the applied version: Bruce, Bruce & Gedeck, Practical Statistics for Data Scientists, "Power and Sample Size".

Heads-up (notation traps):

  • Casella & Berger write the power function as \(\beta(\theta)\). Lesson 2 (and most applied books) used \(\beta\) for the Type II error rate, so power was \(1-\beta\). Same letter, opposite meaning. On this page, \(\beta(\theta)\) always means power.
  • \(\Theta_0\) is the set of parameter values where \(H_0\) is true; \(\Theta_0^c\) is everything else. \(R\) is the rejection region: the data values that make you reject.
  • In Example 8.3.3, \(\sigma\) is known and \(c\) is the cutoff: reject when \((\bar X - \theta_0)/(\sigma/\sqrt n) > c\).

Notes: answer the four boxes below in your own words while you read (a sentence or two each). They reach me with your results, and I'll reply to each.

Definition 8.3.1: what does the power function \(\beta(\theta)\) give you when \(\theta\) is in \(\Theta_0\), and when it's in \(\Theta_0^c\)? What would the ideal power function look like?

For θ in Θ0: the probability of a Type I error (false positive). For θ in Θ0ᶜ: one minus the probability of a Type II error (the chance of correctly rejecting). Ideal: 0 on all of Θ0 and 1 on all of Θ0ᶜ; not attainable except in trivial cases (p. 383).

Example 8.3.2: the second test (reject if \(X\) = 3, 4 or 5) has a smaller Type II error than the first (reject only if \(X = 5\)). Why isn't it simply the better test?

Its Type I error probability is larger too (β2(θ) is larger for θ ≤ 1/2). Fixed n: lowering one error raises the other; the researcher has to choose which error structure is acceptable.

Example 8.3.4: which two requirements pin down the cutoff \(c\) and the sample size \(n\)? Why does \(n\) end up as 5 when the calculation gives 4.49?

Max Type I error .1 (gives c = 1.28, whatever n is) and Type II error at most .2 (power ≥ .8) when θ ≥ θ0 + σ (gives n = 4.49). n must be a whole number, and rounding up keeps power at least .8.

How this connects to the reading: sections 1–3 are §8.3.1 (Definition 8.3.1, Examples 8.3.2–8.3.4) applied to an A/B test. The warm-up and the "revisit" section are review from lessons 2–3.

The running example (an A/B test). A new checkout page is tested with 12,000 users in each group. The old page converts 5.0% of users, the new page 5.6%: an observed lift of 0.6 percentage points. Standard error of the difference: \(\text{SE} = \sqrt{0.05 \times 0.95/12000 + 0.056 \times 0.944/12000} = 0.29\) points. The test rejects "no difference" when \(|z| > 1.96\), where \(z = \text{lift}/\text{SE}\) (two-sided, \(\alpha = 0.05\)). Here \(z \approx 2.08\) and \(p \approx 0.038\).

Warm-up (from memory)

An estimate is 1.4 with standard error 0.3. What is the upper end of its 95% confidence interval?

\(1.4 + 1.96 \times 0.3 = 1.988\).

The new page really does help, but the test says "no significant difference". That outcome is a…

A real effect, missed: false negative, Type II. Power is the chance of avoiding exactly this.

Revisit: a small p-value doesn't mean a big effect

You've missed this one twice, so here it is with numbers. Recall \(z = \text{lift}/\text{SE}\), and the SE shrinks as the groups grow (\(\text{SE} \propto 1/\sqrt n\)). Two real tests:

Users per groupConversionLift (effect size)p
Test A1,000,0005.00% → 5.10%0.1 points0.001
Test B2,0005.0% → 6.5%1.5 points0.04

A has the far smaller p-value and a 15 times smaller effect. Its huge sample makes the SE tiny, so even a 0.1-point lift is many SEs from zero. The p-value measures "detectably not zero", which mixes effect size and sample size.

Test C: 300 users per group, conversion 10% → 14% (lift 4 points). Test D: 500,000 users per group, 10.0% → 10.2% (lift 0.2 points). Which is true?

C: \(p \approx 0.13\) (big effect, too little data to rule out noise). D: \(p \approx 0.0009\) (tiny effect, measured very precisely). Effect size and p-value can point in opposite directions.

1 · The power function (from the reading: Definition 8.3.1)

Casella & Berger define the power function as \(\beta(\theta) = P_\theta(X \in R)\): the probability of rejecting, as a function of the true parameter.1 In the A/B test the parameter is the true lift \(\delta\). Intuition first: suppose the new page really lifts conversion by \(\delta\), and you rerun the whole 12,000-per-group test many times. Each rerun gives a different \(z\). Those \(z\) values scatter around \(\delta/\text{SE}\) with standard deviation 1. Power is the fraction of reruns that land past the 1.96 cutoff.

So the one number that matters is the true effect in SE units, \(d = \delta/\text{SE}\), and

$$\beta(\delta) \approx P(Z > 1.96 - d)$$

(Two-sided tests can also reject on the far negative side; for the effects on this page that adds less than 0.001, so we ignore it.)

Worked example. Power of the 12,000-per-group test if the true lift is 0.5 points (SE 0.29 points).

Effect in SE units: \(d = 0.5 / 0.289 = 1.73\).

Power \(\approx P(Z > 1.96 - 1.73) = P(Z > 0.23) = 0.41\). Check it on the plot: set \(d\) to 1.7 and read the shaded area.

So a real 0.5-point lift would be detected only 41% of the time. And the lift you actually observed, 0.6 points (\(d = 2.08\)), gives power 0.55: a coin flip whether a real effect that size gets flagged.

Same test: 12,000 users per group, SE 0.29 points, reject when \(z > 1.96\). What is the power if the true lift is 0.8 points? Use the plot above. (A decimal.)

\(d = 0.8/0.289 = 2.77\); power \(\approx P(Z > -0.81) = 0.79\).

2 · The trade-off (from the reading: Example 8.3.2)

Example 8.3.2 showed that with the sample size fixed, a test that rejects more easily catches more real effects but also raises more false alarms. You can't lower both error rates just by moving the cutoff.

Same A/B test, still 12,000 users per group. You make it stricter: \(\alpha = 0.01\), so you reject only when \(|z| > 2.58\) instead of 1.96. What happens to the power for a true lift of 0.6 points?

Fewer false positives, more false negatives: the cutoff moves right, past more of the solid curve. Power \(\approx P(Z > 2.58 - 2.08) = P(Z > 0.50) = 0.31\). Only more data (a bigger \(d\)) buys both.

3 · Choosing the sample size (from the reading: Example 8.3.4)

Example 8.3.4 turns the question around: choose \(n\) so the power is high enough for the smallest effect you care about. The common target is power 0.80.

Cutoff 1.96 (two-sided \(\alpha = 0.05\)). Set \(d\), the true effect in standard errors, so that the power is about 0.80.

\(d = 2.8\): that's \(1.96 + 0.84\), where \(P(Z > -0.84) = 0.80\). Rule of thumb: 80% power needs the effect to be about 2.8 standard errors.

Now use \(\text{SE} \propto 1/\sqrt n\): multiplying the sample by \(k\) divides the SE by \(\sqrt k\), so it multiplies \(d\) by \(\sqrt k\). To move \(d\) from its current value up to 2.8:

$$n_{\text{needed}} = n_{\text{now}} \times \left(\frac{2.8}{d_{\text{now}}}\right)^2$$

Worked example. How many users per group for 80% power if the true lift is 0.6 points?

Now: \(n = 12{,}000\), \(d = 0.6/0.289 = 2.08\).

\(n_{\text{needed}} = 12{,}000 \times (2.8/2.08)^2 = 12{,}000 \times 1.81 \approx 21{,}900\) per group. Almost twice the users.

The smallest lift worth shipping is 0.5 points. With 12,000 users per group the SE is 0.289 points. How many users per group give 80% power for a true lift of 0.5 points? (An expression is fine.)

\(d_{\text{now}} = 0.5/0.289 = 1.73\); \(12{,}000 \times (2.8/1.73)^2 \approx 31{,}400\) per group. Smaller effects need a lot more data: halve the effect and you need four times the users.

Proof (from the reading: Example 8.3.3)

Casella & Berger say the normal power function's behaviour is "easy to see". Prove it. Setup: \(X_1, \dots, X_n\) iid \(\text{n}(\theta, \sigma^2)\) with \(\sigma\) known; reject \(H_0: \theta \le \theta_0\) when \((\bar X - \theta_0)/(\sigma/\sqrt n) > c\).

Show that (a) \(\beta(\theta) = P\big(Z > c + \frac{\theta_0 - \theta}{\sigma/\sqrt n}\big)\) with \(Z\) standard normal; (b) \(\beta\) is increasing in \(\theta\); (c) \(\beta(\theta) \to 0\) as \(\theta \to -\infty\) and \(\to 1\) as \(\theta \to \infty\); (d) \(\beta(\theta_0) = \alpha\) when \(P(Z > c) = \alpha\). Plain text is fine (e.g. "Phi", "sqrt(n)").

(a) Subtract and add θ: (X̄−θ0)/(σ/√n) > c ⇔ (X̄−θ)/(σ/√n) > c + (θ0−θ)/(σ/√n); under θ, (X̄−θ)/(σ/√n) ~ n(0,1) because X̄ ~ n(θ, σ²/n). (b) t(θ) = c + (θ0−θ)√n/σ is strictly decreasing in θ; P(Z > t) = 1 − Φ(t) is strictly decreasing in t (the normal density is positive); the composition is strictly increasing. (c) t → +∞ as θ → −∞ and t → −∞ as θ → ∞; 1 − Φ(t) → 0 and → 1. (d) t(θ0) = c. Full marks need the reason X̄ ~ n(θ, σ²/n) and the monotonicity of Φ stated, not just asserted.

Model proof. (a) Under \(\theta\), \(\bar X \sim \text{n}(\theta, \sigma^2/n)\), so \(Z = (\bar X - \theta)/(\sigma/\sqrt n)\) is standard normal. Then \(\frac{\bar X - \theta_0}{\sigma/\sqrt n} > c \iff Z > c + \frac{\theta_0 - \theta}{\sigma/\sqrt n} =: t(\theta)\), so \(\beta(\theta) = 1 - \Phi(t(\theta))\).

(b) \(t(\theta)\) is strictly decreasing in \(\theta\) (slope \(-\sqrt n/\sigma\)), and \(\Phi\) is strictly increasing (its derivative, the normal density, is positive), so \(1 - \Phi(t(\theta))\) is strictly increasing. (c) As \(\theta \to -\infty\), \(t \to \infty\) and \(1 - \Phi(t) \to 0\); as \(\theta \to \infty\), \(t \to -\infty\) and \(1 - \Phi(t) \to 1\). (d) \(t(\theta_0) = c\), so \(\beta(\theta_0) = P(Z > c) = \alpha\).
