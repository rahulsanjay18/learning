## Course description
Classical game theory: games in strategic and extensive form, Nash equilibrium, mixed strategies, von Neumann's minimax theorem,
backward induction, games with incomplete information, and repeated games. By this point you will have met every one of these
ideas in a game you've played (minimax in chess, mixed strategies in poker, backward induction in Nim), so the course puts names
and proofs to them.

## Learning objectives
By the end of this course you can:
1. Find pure and mixed Nash equilibria of a game in strategic form.
2. Prove the minimax theorem for two-player zero-sum games (via linear programming duality) and compute a maximin strategy.
3. Solve extensive-form games by backward induction and find subgame-perfect equilibria.
4. Model incomplete information as a Bayesian game and find its equilibria.
5. Explain how repetition supports cooperation (the folk theorem in outline).
6. Recognize these structures in the games you've played and in strategy problems.
