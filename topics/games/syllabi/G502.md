## Course description
A Level II course on combinatorial game theory, the mathematics of two-player games with perfect information and no chance. When
a game splits into independent parts, you can add the parts like numbers. Some games turn out to be numbers. Impartial games
reduce to Nim through the Sprague–Grundy theorem. The theory explains endgames in Go and many puzzles, and it's a source of design
ideas.

## Learning objectives
By the end of this course you can:
1. Classify positions into outcome classes and compute game sums.
2. Prove the Sprague–Grundy theorem and compute Grundy values for impartial games.
3. Compute the values of games that are numbers, and simplify games using dominated and reversible options.
4. Explain hot games and temperature, and apply them to a simple endgame.
5. Analyse a new game with these tools.

## Texts
- **Required (to buy):** Albert, Nowakowski and Wolfe, *Lessons in Play: An Introduction to Combinatorial Game Theory* (2nd ed., CRC, 2019).
- **Recommended (in your library):** Berlekamp, Conway and Guy, *Winning Ways for Your Mathematical Plays*, Volume 2.
- **Optional (to buy):** Aaron Siegel, *Combinatorial Game Theory* (AMS, 2013), for full proofs.
