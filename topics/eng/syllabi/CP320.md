## Course description
GPU programming with CUDA, from Hwu, Kirk and El Hajj's *Programming Massively Parallel Processors* (4th ed., 2023), Parts I and
II. It covers the CUDA programming model, the GPU's compute and memory architecture, performance tuning, and the core parallel
patterns (convolution, stencil, histogram, reduction, scan and merge). The book teaches CUDA in C, so CP101 is enough background.
Read *CS:APP* Chapter 6 on the memory hierarchy alongside it if you haven't taken CP120. The reps speed up your RL agent's MCTS,
and you write the kernels.

## Learning objectives
By the end of this course you can:
1. Write, launch and debug CUDA kernels with multidimensional grids.
2. Explain warps, scheduling, occupancy and the GPU memory hierarchy.
3. Use shared memory tiling and coalesced access to speed up memory-bound kernels.
4. Implement and optimize the standard parallel patterns: convolution, stencil, histogram, reduction, scan and merge.
5. Profile a kernel with Nsight and explain where its time goes.
6. Speed up a real ML workload on the GPU and measure the result.

## Texts
