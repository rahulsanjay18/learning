## Course description
A Level II course on software design in modern C++, from Klaus Iglberger's *C++ Software Design*. It covers the classic design
patterns as they look in modern C++ (value semantics, type erasure, external polymorphism), with Feathers's *Working Effectively
with Legacy Code* for changing designs safely in existing code.

## Learning objectives
By the end of this course you can:
1. Apply design principles (single responsibility, dependency inversion) at the level of C++ components.
2. Implement Visitor, Strategy, Command, Observer, Adapter, Bridge, Prototype and Decorator in modern C++, with value semantics where it fits.
3. Use type erasure and external polymorphism to decouple code.
4. Get legacy code under test and change it safely.

## Texts
- **Required (to buy):** Klaus Iglberger, *C++ Software Design* (O'Reilly, 2022): Chapters 1 "The Art of Software Design", 2 "The Art of Building Abstractions", 3 "The Purpose of Design Patterns", 4 "The Visitor Design Pattern", 5 "The Strategy and Command Design Patterns", 6 "The Adapter, Observer, and CRTP Design Patterns", 7 "The Bridge, Prototype, and External Polymorphism Design Patterns", 8 "The Type Erasure Design Pattern", 9 "The Decorator Design Pattern".
- **Recommended (in your library):** Gamma et al., *Design Patterns*; Feathers, *Working Effectively with Legacy Code*.
