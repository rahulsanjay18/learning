Course description

An optional Level II capstone: reproduce a recent machine learning paper's key result in public, with code and a write-up. It's the strongest public evidence of research-engineering skill.

Learning objectives

By the end of this course you can:

  1. Reproduce a paper's main result, or explain exactly why it didn't reproduce.
  2. Publish clean code and a clear write-up.

Texts

  • Required: the chosen paper.
