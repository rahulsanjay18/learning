## Course description
An optional quick course on data engineering with Apache Spark and PySpark: the execution model, partitioning, shuffles and joins,
performance tuning, and Structured Streaming. The rep is a self-play analytics job over your RL agent's games, and you write the
code. Spark pays best combined with ML and distributed-systems skills.

## Learning objectives
By the end of this course you can:
1. Explain Spark's execution model: jobs, stages, tasks, and lazy evaluation.
2. Write PySpark DataFrame transformations and read the query plan.
3. Control partitioning and avoid unnecessary shuffles.
4. Choose a join strategy and handle data skew.
5. Write a Structured Streaming job with windowing and watermarks.

## Texts
- **Required (free):** Apache Spark documentation: the RDD and SQL programming guides, the performance tuning guide, and the Structured Streaming guide.
- **Recommended (to buy):** Damji et al., *Learning Spark*, 2nd ed. (O'Reilly, 2020).
