## Course description
One pretest across the C and C++ sequence (CP101 through CP204). For each course it has three kinds of question: predict the
output (or spot the undefined behavior), find the bug, and write a short function. Any course you pass is marked complete, and the
rest teach only the sections you missed.

## Learning objectives
1. Show what you already know of C, the machine level, core C++, modern C++, the standard library and concurrency.
