Course description

Kubernetes for running ML workloads, aimed at the Certified Kubernetes Application Developer (CKAD) exam. The exam is hands-on: you solve tasks on live clusters in a terminal, with the Kubernetes documentation open. The course follows the official CNCF curriculum domains and uses Production Kubernetes for what the exam leaves out. The deliverable is passing CKAD.

Learning objectives

By the end of this course you can:

  1. Build, deploy and update containerized applications on Kubernetes with Deployments, Jobs and CronJobs.
  2. Configure applications with ConfigMaps, Secrets, resource limits and security contexts.
  3. Expose applications with Services and Ingress, and control traffic with NetworkPolicies.
  4. Observe and debug applications with probes, logs and events.
  5. Use Helm and Kustomize, and roll out with blue/green and canary strategies.
  6. Work fast enough in kubectl and Vim to finish a performance-based exam in time.

Texts

  • Required (free): the CNCF CKAD curriculum (github.com/cncf/curriculum), current version: Application Design and Build; Application Deployment; Application Observability and Maintenance; Application Environment, Configuration and Security; Services and Networking. And the kubernetes.io documentation, which is allowed in the exam.
  • Recommended (in your library): Rosso, Lander, Brand and Harris, Production Kubernetes (O'Reilly, 2021): Chapter 1 "A Path to Production", Chapter 5 "Pod Networking", Chapter 6 "Service Routing", Chapter 7 "Secret Management", Chapter 9 "Observability", Chapter 13 "Autoscaling".
  • Practice: the two killer.sh sessions that come with the exam.
