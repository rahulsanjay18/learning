Course description

An optional practice course: reading and extending real C++ machine learning systems. You read the tensor and kernel code in ggml/llama.cpp, then write a PyTorch C++/CUDA extension of your own.

Learning objectives

By the end of this course you can:

  1. Find your way around a large C++ ML codebase and explain its main data structures.
  2. Write and benchmark a PyTorch C++/CUDA extension.

Texts

  • Required (free): the ggml and llama.cpp source code; PyTorch's tutorial "Custom C++ and CUDA Extensions".
