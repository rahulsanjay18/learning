Course description

An optional practice course that runs for as long as one real project does. You pick a cross-team project at work and run it with the tools from the staff courses: kickoff document, design document, decision log and retrospective. The write-up becomes the centerpiece of your promotion packet or interview stories.

Learning objectives

By the end of this course you can:

  1. Run a staff-scope project from kickoff to retrospective with written artifacts at each stage.
  2. Measure and report the project's impact.

Texts

  • Required: your notes from SE110, SE140 and SE150.
