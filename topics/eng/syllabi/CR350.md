## Course description
An optional language course: Rust, used for systems, infrastructure, embedded and crypto work, and reported among the best-paid languages. It's easier after CP101, since Rust's ownership rules formalize what careful C programmers already do.

## Learning objectives
By the end of this course you can:
1. Write Rust that passes the borrow checker, and explain ownership, borrowing and lifetimes.
2. Use enums, pattern matching, traits and generics idiomatically.
3. Handle errors with Result and write concurrent Rust safely.
4. Port one small component of your engine to Rust and compare.

## Texts
- **Required (free):** Klabnik and Nichols, *The Rust Programming Language* (doc.rust-lang.org/book): Chapters 1–10, 13, 15 and 16.
