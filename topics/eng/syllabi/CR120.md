## Course description
An optional course on building applications with large language models: foundation models, evaluation, prompt engineering,
retrieval-augmented generation, agents and tool use, fine-tuning trade-offs, dataset engineering, and the architecture of AI
products. The main text is Chip Huyen's *AI Engineering*. The deliverable is a public agent with an evaluation suite. If you're
eligible, the course also prepares you for Anthropic's Claude Certified Architect exam.

## Learning objectives
By the end of this course you can:
1. Explain how foundation models are trained and sampled, and what that implies for applications.
2. Design an evaluation for an open-ended AI system, including AI-as-judge and its failure modes.
3. Write and test prompts systematically, and defend against prompt injection.
4. Build retrieval-augmented generation and agents with tools, using the Model Context Protocol.
5. Decide when to fine-tune instead of prompting or retrieving.
6. Design the architecture and feedback loop for an AI product.

## Texts
- **Required (to buy):** Chip Huyen, *AI Engineering: Building Applications with Foundation Models* (O'Reilly, 2025): Chapters 1 "Introduction to Building AI Applications with Foundation Models", 2 "Understanding Foundation Models", 3 "Evaluation Methodology", 4 "Evaluate AI Systems", 5 "Prompt Engineering", 6 "RAG and Agents", 7 "Finetuning", 8 "Dataset Engineering", 10 "AI Engineering Architecture and User Feedback".
- **Required (free):** the Model Context Protocol specification (modelcontextprotocol.io); Anthropic's documentation and Anthropic Academy courses.
