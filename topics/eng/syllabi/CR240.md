## Course description
An optional certification course: HashiCorp's Terraform Associate (004), which tests Terraform 1.12. You'll already use Terraform for your AWS training fleet in AW101, so this course fills the gaps the exam covers and you haven't used.

## Learning objectives
By the end of this course you can:
1. Explain Terraform's workflow, state, providers and modules.
2. Use workspaces, imports, and state manipulation safely.
3. Pass the exam.

## Texts
- **Required (free):** HashiCorp, *Terraform Associate (004) exam content list* and the official study tutorials; Terraform documentation.
- **Recommended:** your AW101 Terraform code.
