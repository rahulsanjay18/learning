## Course description
The AWS foundations an ML engineer needs, learned by moving your RL training fleet onto Terraform-managed AWS: IAM, S3, VPC
networking, EC2 spot instances, ECR, budgets, and Terraform state. Each lesson pairs an AWS area with one of the 3dChessRLAgent
infrastructure tickets. The foundations modules of your 2024 Solutions Architect course are the main reading. AWS documentation
fills anything newer.

## Learning objectives
By the end of this course you can:
1. Write least-privilege IAM policies and explain roles, policies and trust relationships.
2. Configure S3 buckets for training data and artifacts, including encryption and lifecycle rules.
3. Design a simple VPC with public and private subnets, and explain what spot workers need to reach.
4. Launch and manage EC2 spot capacity with launch templates, and handle interruptions.
5. Manage AWS infrastructure with Terraform, including remote state, imports and a CI plan gate with OIDC.
6. Set budgets and alerts so a training run can't overspend.

## Texts
- **Required:** your 2024 AWS Solutions Architect – Associate course (the slides are in your library): the modules on IAM, S3, VPC, EC2, ECR and cost management.
- **Required (free):** AWS documentation for each service; HashiCorp's Terraform documentation on state, import and the AWS provider.
