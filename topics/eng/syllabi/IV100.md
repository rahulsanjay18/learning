## Course description
Continuous interview practice at the big-tech staff bar. Each Thursday is one mock round, rotating through six types: coding
(timed, in Vim), system design, ML system design, AI-assisted coding, behavioral and leadership, and project deep dive. Whichever
type you're weakest at comes up twice as often. About one design prompt in three is a standard one (rate limiter, news feed and so
on), and the rest come from your own projects. Each of your own prompts has a standard twin. In the last weeks before a real loop,
almost all prompts are standard, so practice looks like the test.

## Learning objectives
By the end of this course you can:
1. Solve medium and hard coding problems in time, in Vim, while explaining your reasoning.
2. Run a 45-minute system design round: requirements, estimates, high-level design, deep dives and trade-offs.
3. Run an ML system design round from problem framing to monitoring.
4. Tell staff-scope stories that show scope, influence and judgment.
5. Defend a past project in a deep dive, including what you'd do differently.
6. Use an AI assistant well in an AI-assisted coding round.

## Texts
- **Required (to buy):** Alex Xu, *System Design Interview*, Volume 1 (2020) and Volume 2 (with Sahn Lam, 2022). Ali Aminian and Alex Xu, *Machine Learning System Design Interview* (2023).
- **Recommended (in your library):** Kleppmann, *Designing Data-Intensive Applications*; Huyen, *Designing Machine Learning Systems*; Skiena, *The Algorithm Design Manual*.
- **Free:** Chip Huyen, *Introduction to Machine Learning Interviews*; NeetCode problem lists.

|---|---|---|
