Course description

Serving models fast and cheaply: quantization, batching, KV caches and paged attention, speculative decoding, serving frameworks (vLLM, TensorRT-LLM), and CUDA where it matters. It builds on CP320 (CUDA) and CR130 (fine-tuning). The deliverable is a model served on Kubernetes with a published latency and cost benchmark. The reps build your RL agent's inference service and endpoint.

Learning objectives

By the end of this course you can:

  1. Explain where inference time and memory go, and calculate them for a given model and batch.
  2. Quantize a model and measure the accuracy cost.
  3. Explain continuous batching, paged attention and speculative decoding.
  4. Serve a model with vLLM and tune it for throughput and latency.
  5. Benchmark honestly: latency percentiles, throughput, and cost per token.

Texts

  • Required (to buy): Huyen, AI Engineering, Chapter 9 "Inference Optimization".
  • Required (free): vLLM documentation; Kwon et al., "Efficient Memory Management for Large Language Model Serving with PagedAttention" (SOSP 2023).
  • Recommended (in your library): Huyen, Designing Machine Learning Systems, Chapter 7.
