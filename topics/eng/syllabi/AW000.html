Course description

A placement for the AWS courses. It checks the AWS foundations the exam assumes and each of the four MLA-C02 exam domains, and asks you to pick an exam date. Any domain you already know gets skipped in AW201.

Learning objectives

By the end of this course you can:

  1. Mark each of the four exam domains as known, shaky or new, from a short pretest per domain.
  2. Say which AWS services your RL training fleet already uses and which exam domains they cover.
  3. Set a target exam date.

Texts

  • Required: AWS, AWS Certified Machine Learning Engineer – Associate (MLA-C02) Exam Guide (free on the AWS documentation site): the domain list and weights.
