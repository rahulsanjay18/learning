## Course description
Security for AI systems and the cloud: threat modeling, cloud identity and network security, application security for your web
and desktop clients, and the new attack surface of LLM applications (prompt injection, data and model supply chains, insecure tool
use). Security hiring has grown quickly and AI security roles pay a premium. The reps are real threat models and security reviews
for your projects. A security certification (the AWS one, or similar) is an optional goal at the end.

## Learning objectives
By the end of this course you can:
1. Write a threat model with STRIDE and turn it into prioritized fixes.
2. Secure cloud identity and networks on AWS: least privilege, isolation, secrets and logging.
3. Review a web or desktop client for common vulnerabilities (OWASP Top 10, Electron's security checklist).
4. Explain the OWASP Top 10 for LLM applications and design defenses for prompt injection and unsafe tool use.
5. Secure a machine learning supply chain: data, model weights and dependencies.

## Texts
- **Required (free):** Adam Shostack, *Threat Modeling: Designing for Security* (Wiley, 2014; to buy), Part I. OWASP Top 10 and OWASP Top 10 for LLM Applications. AWS Security Reference Architecture. Electron's security checklist.
- **Recommended (in your library):** Rosso et al., *Production Kubernetes*, Chapter 7 "Secret Management", Chapter 8 "Admission Control", Chapter 15 "Software Supply Chain".
