## Course description
Concurrent programming in C++, from Anthony Williams's *C++ Concurrency in Action* (2nd ed., C++17): threads, sharing data and
mutexes, synchronization with condition variables and futures, the C++ memory model and atomics, lock-based and lock-free data
structures, designing concurrent code, and the parallel algorithms. This matters directly for your engine and for MCTS with many
search threads.

## Learning objectives
By the end of this course you can:
1. Start, join and manage threads safely.
2. Protect shared data with mutexes and avoid deadlock.
3. Synchronize with condition variables, futures and promises.
4. Explain the C++ memory model and memory orderings, and use atomics correctly.
5. Design a thread-safe data structure, with and without locks.
6. Use the C++17 parallel algorithms, and test and debug concurrent code.

## Texts
- **Required (to buy):** Anthony Williams, *C++ Concurrency in Action*, 2nd ed. (Manning, 2019): Chapters 1–8, 10 and 11.
- **Recommended (in your library):** Arpaci-Dusseau, *Operating Systems: Three Easy Pieces*, the concurrency chapters (locks, condition variables, common concurrency bugs).
- **Optional (in your library):** Gustedt, *Modern C*, "Threads" and "Atomic access and memory consistency", for the C view.
