## Course description
An optional language course: Go, the language of cloud infrastructure (Kubernetes and Terraform are written in it). The course covers the language, its concurrency model and its standard library, and ends with a small service.

## Learning objectives
By the end of this course you can:
1. Write idiomatic Go with interfaces, error handling and packages.
2. Use goroutines and channels correctly.
3. Build and test a small HTTP service.

## Texts
- **Required (to buy):** Donovan and Kernighan, *The Go Programming Language* (Addison-Wesley, 2015): Chapters 1–9.
- **Free alternative:** the Go Tour (go.dev/tour).
