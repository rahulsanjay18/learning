Course description

An optional course on game engine architecture, from Jason Gregory's book of that name: engine support systems, resources, the game loop and real-time simulation, input, debugging tools, and gameplay foundations. It applies directly to a desktop or 3D client for your chess variant.

Learning objectives

By the end of this course you can:

  1. Describe the layers of a game engine and what each one does.
  2. Implement a fixed-timestep game loop and explain its trade-offs.
  3. Design memory allocation and resource management for an engine.
  4. Build debugging tools into an engine.
  5. Design a runtime gameplay object model.

Texts

  • Required (to buy): Jason Gregory, Game Engine Architecture, 3rd ed. (CRC, 2018): Chapter 1 "Introduction", 3 "Fundamentals of Software Engineering for Games", 4 "Parallelism and Concurrent Programming", 6 "Engine Support Systems", 7 "Resources and the File System", 8 "The Game Loop and Real-Time Simulation", 9 "Human Interface Devices", 10 "Tools for Debugging and Development", 15 "Introduction to Gameplay Systems", 16 "Runtime Gameplay Foundation Systems".
  • Recommended (in your library): McShaffry and Graham, Game Coding Complete, 4th ed.
  • Not used: Unity in Action. It teaches C#, and this course is about C++.
