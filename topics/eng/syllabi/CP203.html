Course description

Generic programming and the C++ standard library in depth, from Josuttis's The C++ Standard Library: the STL's design (containers, iterators, algorithms and function objects), the container member functions in detail, strings, utilities, and templates from C++ Primer Chapter 16. It ends with C++20 concepts and ranges, which change how generic code is written.

Learning objectives

By the end of this course you can:

  1. Explain the STL's separation of containers, iterators and algorithms, and why it works.
  2. Choose the right container for a workload from its complexity guarantees and memory behavior.
  3. Use iterator categories and adaptors correctly, and avoid iterator invalidation.
  4. Use the standard algorithms instead of hand-written loops, with lambdas as function objects.
  5. Write function and class templates, including variadic templates and simple traits.
  6. Constrain templates with concepts and use the ranges library.

Texts

  • Required (in your library): Nicolai Josuttis, The C++ Standard Library, 2nd ed. (2012): Chapter 5 "Utilities", Chapter 6 "The Standard Template Library", Chapter 7 "STL Containers", Chapter 9 "STL Iterators", Chapter 10 "STL Function Objects and Using Lambdas", Chapter 11 "STL Algorithms", Chapter 13 "Strings".
  • Required (in your library): C++ Primer, 5th ed., Chapter 16 "Templates and Generic Programming".
  • Required (to buy): Stroustrup, A Tour of C++, 3rd ed., the chapters on concepts, algorithms and ranges.
