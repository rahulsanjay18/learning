Course description

An optional course on Linux systems programming from Michael Kerrisk's The Linux Programming Interface: file I/O, processes, memory allocation, signals, threads, pipes, memory mappings, sockets and event-driven I/O. It's what you need to write servers and tools that behave well on Linux.

Learning objectives

By the end of this course you can:

  1. Use the file I/O system calls and explain buffering at each layer.
  2. Create, monitor and replace processes (fork, wait, exec) without leaking resources.
  3. Handle signals safely.
  4. Use pipes and memory mappings for interprocess communication.
  5. Write a TCP server with sockets and handle many clients with epoll.

Texts

  • Required (to buy): Michael Kerrisk, The Linux Programming Interface (No Starch, 2010), by topic: file I/O, processes, memory allocation, file I/O buffering, signals, process creation and termination, program execution, threads, pipes and FIFOs, memory mappings, sockets, and alternative I/O models.
  • Recommended (in your library): Arpaci-Dusseau, Operating Systems: Three Easy Pieces, the persistence chapters.
  • Reference: the man pages at man7.org.
