## Course description
Core C++ from *C++ Primer* (5th ed., C++11), with the C++20 additions from Stroustrup's *A Tour of C++*. Part I covers the basics,
Part II the standard library, and Part III classes, copy control, operator overloading, inheritance and templates. The pretest
should skip a good deal. The rest is taught at the pace of an experienced programmer learning a new language, not a beginner.

## Learning objectives
By the end of this course you can:
1. Use C++ types, references, const and auto correctly, and explain how they differ from C.
2. Use strings, vectors, the sequential and associative containers, and the generic algorithms.
3. Manage dynamic memory with smart pointers instead of new and delete.
4. Write classes with correct copy control (the rule of five) and explain move semantics at a basic level.
5. Overload operators and conversions sensibly.
6. Use inheritance and virtual functions, and know when not to.
7. Write simple function and class templates, and use C++20 concepts to constrain them.

## Texts
- **Required (in your library):** Lippman, Lajoie and Moo, *C++ Primer*, 5th ed. (2012): Part I (Chapters 2–7), Part II (Chapters 9–12), Part III (Chapters 13–16).
- **Required (to buy):** Stroustrup, *A Tour of C++*, 3rd ed. (2022), for C++20: concepts, ranges and modules.
- **Reference:** cppreference.com.
- **Optional (in your library):** Stroustrup, *Programming: Principles and Practice Using C++*, 2nd ed., for exercises.
