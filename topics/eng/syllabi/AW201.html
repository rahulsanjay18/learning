Course description

Machine learning on AWS, organized by the four domains of the MLA-C02 exam: data preparation (28%), model development (24%), deployment and orchestration (24%), and monitoring, maintenance and security (24%). Each lesson compares how your RL agent does something today (EC2, Ray, MLflow) with the SageMaker and Bedrock way that the exam tests. Domains the placement showed you know are skipped.

Learning objectives

By the end of this course you can:

  1. Prepare and store data for ML on AWS: ingestion, transformation, feature stores, and data quality and bias checks.
  2. Choose an approach to model development (built-in algorithm, custom training, foundation model through Bedrock), and train and tune on SageMaker.
  3. Choose a deployment option (real-time, serverless, asynchronous, batch) for a given workload, and set up CI/CD for models.
  4. Monitor models for drift and performance, and secure ML resources with IAM, encryption and network isolation.
  5. Explain where your own RL stack differs from the SageMaker approach, and why.

Texts

  • Required: AWS, MLA-C02 Exam Guide (free): every task statement in the four domains.
  • Required (free): the SageMaker AI and Amazon Bedrock developer guides, the sections each lesson names.
  • Recommended (in your library): Huyen, Designing Machine Learning Systems, Chapters 4–9. McMahon, Machine Learning Engineering with Python.
