## Course description
An optional certification course: Databricks Certified Generative AI Engineer Associate. It's popular with data-platform employers and pairs naturally with the Spark course (CR170). The exam changed in March 2026.

## Learning objectives
By the end of this course you can:
1. Build retrieval-augmented and agent applications on Databricks.
2. Use Databricks' tools for vector search, model serving, evaluation and governance.
3. Pass the exam.

## Texts
- **Required (free):** the Databricks exam guide for the certification; Databricks Academy's matching course; Databricks documentation.
- **Recommended:** your CR120 and CR170 notes.
