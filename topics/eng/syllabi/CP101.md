## Course description
C as it's written today (C17), from Jens Gustedt's *Modern C*. We cover control flow, expressions, types and values, arrays and
structures, functions, the standard library, pointers, the C memory model, storage duration, and the rules that make C code
portable and free of undefined behavior. Your 3D chess engine is written in C, so the exercises and the rep use it.

## Learning objectives
By the end of this course you can:
1. Write C17 that compiles cleanly with warnings on and has no undefined behavior you can't account for.
2. Explain C's integer types, conversions and overflow rules, and avoid the common traps.
3. Use pointers correctly: arithmetic, the array–pointer relationship, null pointers, function pointers and opaque types.
4. Explain C's memory model: effective type, alignment, and the storage durations.
5. Organize a C library with clean headers and documented interfaces.
6. Read and explain C declarations, however tangled.

## Texts
- **Required (in your library):** Jens Gustedt, *Modern C* (2018 edition, C17): Level 1 "Acquaintance" ("Everything is about control", "Expressing computations", "Basic values and data", "Aggregate data types", "Functions", "C Library functions") and Level 2 "Cognition" ("Style", "Organization and documentation", "Pointers", "The C memory model", "Storage", "More involved use of the C library").
- **Recommended (in your library):** Peter van der Linden, *Expert C Programming*: the chapters on declarations and on arrays versus pointers.
- **Optional (in your library):** Kernighan and Ritchie, *The C Programming Language*, 2nd ed., for its exercises.
