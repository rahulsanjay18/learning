Course description

An optional certification course: Microsoft's Azure AI Apps and Agents Developer Associate (AI-103), which replaced AI-102 in 2026. It covers building agentic applications on Azure AI Foundry. Take it only if Azure matters to an employer.

Learning objectives

By the end of this course you can:

  1. Build and deploy an agentic application on Azure AI Foundry.
  2. Use Azure's model catalog, retrieval and safety tools.
  3. Pass the exam.

Texts

  • Required (free): Microsoft Learn, the AI-103 study guide and learning paths; Azure AI Foundry documentation.
  • Recommended: your CR120 notes.
