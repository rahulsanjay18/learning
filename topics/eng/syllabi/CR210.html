Course description

An optional certification course: Google Cloud's Professional Machine Learning Engineer. It's the other major cloud ML certification, and it now covers Vertex AI's generative AI and agent tools. Most of what you learn for the AWS exam carries over. This course covers the Google-specific services and the exam's framing.

Learning objectives

By the end of this course you can:

  1. Map each exam domain to the Google Cloud services it tests.
  2. Build, train and deploy a model on Vertex AI, including pipelines and monitoring.
  3. Explain where Google's approach differs from SageMaker's.
  4. Pass the exam.

Texts

  • Required (free): Google Cloud, Professional Machine Learning Engineer exam guide; the Vertex AI documentation; Google Cloud Skills Boost learning path for the exam.
  • Recommended (in your library): Huyen, Designing Machine Learning Systems.
