Course description

An optional capstone: one merged pull request to a real open-source C or C++ project you use. Finding a good first issue, working with maintainers and getting through code review are the skills it trains.

Learning objectives

By the end of this course you can:

  1. Find and scope a contribution to an open-source C or C++ project.
  2. Work through code review with maintainers to a merge.

Texts

  • Required: the chosen project's contributing guide.
