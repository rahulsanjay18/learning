The OPT model

3 levels, 5 phases. Sourced from NASM's OPT pages12.

LevelPhaseFingerprintAcute variables
Stabilization1 · Stabilization EnduranceSlow, controlled instability; most clients start here12–20 reps, lighter load
Strength2 · Strength EnduranceSuperset: strength exercise → similar stability exercise2–4 sets · 8–12 reps each (16–24 per superset)
3 · Muscular Development / HypertrophyMuscle growth3–6 sets · 6–12 reps · 75–85% 1RM
4 · Maximal StrengthMaximal force4–6 sets · 1–5 reps · 85–100% 1RM
Power5 · PowerSuperset: heavy exercise → light explosive exercise1–5 reps heavy, then 8–10 reps fast

Rules of thumb

  • Two supersets: the partner decides the phase. Stability partner → Phase 2. Explosive partner → Phase 5.
  • Go only as far up as the goal needs, then cycle (e.g. fat loss: 1 ↔ 2).3
  • Phase 3 = “Hypertrophy” in older material and the blueprint; “Muscular Development/Hypertrophy” on NASM's current page.

Phase 1 sets, tempo and rest aren't on NASM's public page; we'll add them from a verified source in a later lesson.
